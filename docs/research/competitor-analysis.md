# 篮球进球识别竞品调研

> 调研时间：2026-11-14。信息来源为各产品官网、App Store 与应用宝页面（链接见文末），
> 价格、功能与支持的运动以官方最新说明为准；本文没有实测各产品的识别准确率。
> 范围：能自动识别投篮/进球、自动生成片段，或提供投篮数据的产品；
> 纯人工剪辑、纯战术分析工具只在相邻品类中简要提及。
> GitHub 开源方案的调研见 [shot-recognition.md](shot-recognition.md)，本文只覆盖商业产品。

## 1. 结论摘要

1. **竞品可以分成四层**：消费级手机 App（HomeCourt、篮迹、LikeSports、ShotAI 等）、
   智能硬件/传感系统（ShotTracker、Noah、Swish Hoop）、场馆与赛事视频平台
   （Pixellot、Hudl、Spiideo、Veo、我奥体育），以及开源方案（见另一篇调研）。
2. **「手机单摄 + 纯软件 + 自动识别命中/不中」已经不是空白**：HomeCourt、篮迹、
   ShotAI、AI Basketball Shot Training 都能用手机完成投篮计数和命中率统计，
   但普遍面向**单人投篮训练**，不是全场/半场的比赛集锦。
3. **和本项目最接近的是 LikeSports（北京来氪体育）**：手机拍摄或上传视频后，
   自动剪出每一次投篮/进球、统计出手数与命中率、按球员生成个人集锦，并套用
   「五佳球」「连中」等模板，还渲染篮球轨迹。它把「自动识别 + 自动剪辑」做成了完整卖点，
   是本项目需要重点跟踪的直接竞品。
4. **「自动识别进球 + 自动生成片段」仍是相对稀缺的组合**：训练类 App 多聚焦单人训练，
   场馆类平台强在直播与赛事服务，面向业余半场、手机拍摄、低成本出片的产品不多。
5. **硬件/场馆方案的精度与数据深度明显更高**，代价是需要传感器、多机位或固定安装，
   价格以报价制为主。它们不是 MVP 阶段的直接竞争对手，但定义了「专业级」的能力上限。
6. **价格带**：已核实 HomeCourt 为 $7.99/月、$69.99/年，团队 $1.50/人/月；
   其余训练 App 多为免费下载 + 内购/订阅；场馆与硬件系统不公开标价，按设备 + 年费报价。

## 3. 消费级手机 App

### 3.1 HomeCourt

- **产品形态**：手机 App，官方称是「互动式篮球训练 App」，用手机记录
  投篮、动作和统计数据，给出实时反馈、技能评分和训练计划，并支持线上挑战/组队。
- **特点**：
  - NBA 官方合作伙伴，邀请多名 NBA/WNBA 球员出镜课程与挑战，品牌和内容壁垒强；
  - 把训练做成游戏化体验（drills、虚拟比赛、排行榜），用户留存是核心；
  - 有面向球队、训练营、体育课的团队版，按人/月收费。
- **价格**：HomeCourt+ $7.99/月或 $69.99/年；团队版 $1.50/人/月（年付）或 $1.99/人/月（3 个月）。
- **局限**：重心是单人训练与技能提升，不是比赛/半场集锦；没有公开的「按球员自动剪集锦」能力。

### 3.2 篮迹

- **产品形态**：iPhone App，定位「投篮自动计数器 / AI 投篮分析」。
- **特点**：
  - 用手机摄像头自动识别出手、篮筐和场地线，统计进球数、命中率，生成出手点位图和热力图；
  - 提供投篮姿态分析，对比「标准动作」给出改进建议；
  - 按周/月/生涯回顾训练，自动生成高光时刻、连续进球等短视频并可保存到相册；
  - 有全服进球数排行榜和练前指导，偏训练社区。
- **价格**：免费下载 + App 内购买。
- **局限**：面向单人投篮训练；中文市场直接竞品，功能组合（数据 + 剪辑 + 社区）与本项目高度重叠。

### 3.3 LikeSports（北京来氪体育科技）

- **产品形态**：手机 App（应用宝提供 Android 版），定位「篮球、匹克球 AI 视频剪辑」，两小时视频一分钟出高光集锦。
- **特点**：
  - 手机拍摄或上传视频后，自动识别并剪出**每一次投篮和进球**，可直接回看进球片段；
  - 自动统计训练/比赛的出手数和命中率；
  - 自动识别进球的投篮人，为每名球员生成专属个人集锦；
  - 支持单个投篮、全部进球、个人集锦、五佳球、连中模板等导出，并在视频中渲染篮球轨迹；
  - 支持云端上传与分享，强调「告别手动剪辑」。
- **价格**：页面未标价；国内同类产品多为免费下载 + 内购，需实测确认。
- **局限**：更像剪辑工具，投篮数据维度不如训练类 App 深；公开信息未说明识别准确率与支持的机位条件。
- **意义**：与本项目「识别进球 → 生成片段」的路径几乎一致，是最需要对照的产品。

### 3.4 ShotAI

- **产品形态**：iPhone App，个人训练/家长拍娃/教练快速反馈。
- **特点**：
  - 对录制或导入的视频做自动球跟踪与投篮检测，识别命中/不中，并自动生成可回看、可导出的投篮片段；
  - 提供投篮图、命中率趋势、排行榜；可选投篮姿态、场上位置和球员标注等进阶分析；
  - 官方强调分析主要在 iPhone 本地完成，完整视频由用户掌控。
- **价格**：免费下载，部分功能需要会员。
- **局限**：以训练视频为主，不是全场赛事直播/集锦产品；本地分析对机型有要求。

### 3.5 AI Basketball Shot Training

- **产品形态**：手机 App，把手机变成「个人投篮教练」。
- **特点**：
  - 摄像头对准篮筐后实时识别命中/不中，提供即时语音反馈、投篮图和本次训练视频回放；
  - 自动生成高光集锦；
  - 附带运球、控球、敏捷性三个小游戏，扩展训练场景；
  - 无需可穿戴设备或额外硬件。
- **价格**：免费下载，Pro 订阅解锁全部模式和详细分析。
- **局限**：训练工具定位；功能深度和内容生态弱于 HomeCourt。

### 3.6 Ballogy

- **产品形态**：手机 App + 任意可穿戴，面向球员、教练、训练营。
- **特点**：
  - 把手机对准篮筐/篮网/单杠，用物体检测自动记录训练和投篮次数；
  - 用「Move、Train、Recover」三项分数做能力评估，可管理球队、训练营和测试活动；
  - 记录跑步、力量训练，并接入可穿戴设备做恢复管理。
- **价格**：免费下载 + 订阅（以商店为准）。
- **局限**：核心是体能与技能评估，不是比赛进球识别或自动集锦。

## 4. 智能硬件与传感系统

### 4.1 ShotTracker

- **产品形态**：传感器系统，面向球队、场馆和赛事。
- **工作方式**：球馆天花板的接收锚点建立球场三维坐标，配合内置传感器的篮球和球员佩戴的标签，
  实时追踪球和球员位置，输出出手/命中、投篮图、阵容组合和箱式数据。
- **特点**：实时性强、数据维度深；已扩展到视频、AI 球探、替补席分析和球迷互动等产品线；
  客户覆盖大学、职业队和赛事。
- **价格**：报价制，按场馆/球队部署。
- **局限**：需要改造球馆和专用球、标签，个人用户无法使用。

### 4.2 Noah Basketball

- **产品形态**：投篮追踪与反馈系统（Noah Pro、Noah Backboard、Noah Broadcast 等）+ HOOPS App。
- **特点**：
  - 采集投篮弧线、深度、左右偏差等关键指标，提供即时语音反馈和实时数据；
  - 用于纠正投篮动作、建立肌肉记忆，也支持比赛数据跟踪；
  - 官网称 28 支 NBA 球队、200+ NCAA 项目、1000+ 高中在使用，职业训练场景渗透率高。
- **价格**：报价制。
- **局限**：训练/场馆设备，不是消费级手机产品；不解决业余比赛自动集锦问题。

### 4.3 Swish Hoop

- **产品形态**：挂在篮网上的 Shot Monitor 传感器 + 手机 App（+ 可选记分牌）。
- **特点**：传感器自动记录每次出手和命中，App 展示训练数据；安装简单、无需改造球场。
- **价格**：硬件单独购买，App 在商店标价 0 元。
- **局限**：只覆盖一个篮筐，硬件成本；无比赛视频与自动集锦。

## 5. 场馆与赛事视频平台

### 5.1 Pixellot

- **产品形态**：多机位自动摄像系统 + OTT/分析平台，面向联赛、场馆、转播商和球队。
- **特点**：
  - 多摄像头阵列覆盖全场，AI 自动跟拍、自动导播，无需摄像师；
  - 提供直播、点播、自动集锦和篮球分析；
  - 官方称其篮球方案获得 FIBA 认可，适合联赛和场馆规模化部署。
- **价格**：报价制（设备 + 服务）。
- **局限**：场馆级部署，个人和半场场景成本过高；自动集锦不等于逐球命中识别。

### 5.2 Hudl Focus / Hudl Assist

- **产品形态**：Focus Indoor 等 AI 自动跟拍摄像机 + Hudl 视频分析平台。
- **特点**：自动录制、上传、直播，AI 跟拍球员/比赛；配合 Hudl Assist 提供人工/半自动的
  数据统计与报告，Sportscode 支持专业战术分析。
- **价格**：硬件 + 订阅，按学校/球队报价。
- **局限**：公开页面未见「自动识别投篮命中」能力，统计依赖 Assist 服务；
  面向学校和俱乐部，不是个人拍完即出集锦的工具。

### 5.3 Spiideo

- **产品形态**：云端摄像系统与视频分析平台，覆盖篮球、足球、冰球等。
- **特点**：固定机位全景/多角度采集，云端自动制作、自动集锦、回放与战术分析；
  篮球场景强调全场视频、直播和轻量化部署。
- **价格**：报价制。
- **局限**：团队/场馆工具，不面向个人；公开信息未强调逐球命中识别。

### 5.4 Veo

- **产品形态**：自动跟拍摄像机（Veo Cam）+ 订阅制编辑/分析平台。
- **特点**：
  - 自动跟拍、直播，AI 自动标记关键时刻，Veo Editor 用于回看、剪辑和分享；
  - Player Spotlight 可按球员自动生成集锦；
  - 官网支持篮球，但自动事件（进球、射门、角球等）的描述更偏足球，篮球场景以录像/直播/集锦为主。
- **价格**：硬件 + 订阅，官网可获取报价。
- **局限**：需要专用摄像硬件；篮球的逐球识别能力未见明确说明。

### 5.5 我奥体育（我奥篮球）

- **产品形态**：面向协会、赛事公司、场馆和培训机构的数字化平台 + 智能运动相机。
- **特点**：
  - 提供赛事报名、技术统计、视频直播、回放、集锦和赛事管理；
  - 「智能运动相机」支持 AI 识别并跟踪运动员/篮球，一键直播，可同时录左右半场；
  - 官网称已服务 15 万+ 体育赛事、165 万场比赛、1600 万体育用户。
- **价格**：设备 + 服务报价。
- **局限**：B2B 赛事/场馆方案，个人用户无法直接用手机获得同等能力；
  公开信息未明确说明是否输出逐球命中/不中数据。

## 8. 对本项目的启示

1. **定位**：坚持「手机拍摄 → 上传 → 自动识别进球 → 生成片段」的零硬件路径，
   面向业余半场、野球和训练场景。多数训练类 App 聚焦单人训练与数据，
   场馆类方案需要专用相机，面向业余半场、手机拍摄的自动集锦仍是空档。
2. **最直接的对标**：LikeSports（自动剪辑）、篮迹（数据 + 剪辑 + 社区）、
   HomeCourt（品牌与训练内容）。需要持续跟踪 LikeSports 的识别准确率、支持的机位和收费方式。
3. **功能优先级**：
   - P0：命中/不中识别准确率、进球片段（当前已实现前后 5 秒）、结果页展示；
   - P1：命中率/出手点等统计、结果人工纠正、片段分享模板、手动圈定篮筐的易用性；
   - P2：按球员自动归类集锦、连中/五佳球模板、云端分享。
4. **技术路线**：单目手机视频的瓶颈在遮挡、机位和光照；当前 OpenCV 基线只是验证链路，
   下一步按 [shot-recognition.md](shot-recognition.md) 的建议升级为
   「检测 + 跟踪 + 轨迹穿筐判定」，并用自采数据建立评估集，别只参考竞品自报指标。
5. **商业化**：可参考 HomeCourt 的个人订阅 + 团队按人计费；国内可先用免费额度 + 片段/高清导出付费，
   再探索场馆/训练营合作。片段是比「数据图表」更直观的付费点。
6. **风险**：
   - 单目准确率不够会导致用户不信任，宁可少报也不要错报（与当前「低置信度要求手动圈筐」策略一致）；
   - 大厂/硬件商下沉做手机方案，或 LikeSports、篮迹快速迭代；
   - 视频上传涉及隐私与存储成本，后续可评估端侧推理。
